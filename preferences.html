Display

Bookmarks are added to the video's chapter list so IINA draws them as ticks on the progress bar. Also enable Settings > UI > Show chapter positions in progress bar. Bookmarks will appear in the Chapters panel and in chapter navigation as well.

Keyboard shortcuts

Use mpv key names: Meta = ⌘, Alt = ⌥, Ctrl = ⌃, an uppercase letter implies ⇧ (e.g. Meta+B = ⇧⌘B). Special keys: LEFT, RIGHT, UP, DOWN, BS (delete). Type none to disable a shortcut. Changes apply when the next file is opened.
